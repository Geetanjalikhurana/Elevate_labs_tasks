## 📌 Objective
Automate data collection from a public news website by developing a Python web scraping script using `requests` and `BeautifulSoup4`. The script fetches live HTML content, extracts headline titles from HTML tags (`<h2>`/`<h3>`), cleans/deduplicates the extracted text, prints preview output to the console, and writes the complete set of headlines into a structured `.txt` file (`headlines.txt`).

---

## 🛠️ Tools & Technologies Used
- **Language:** Python 3.10+
- **HTTP Client Library:** `requests` (used to send HTTP GET requests and retrieve page HTML)
- **HTML Parsing Library:** `beautifulsoup4` (used to parse DOM tree and extract headline tags)
- **Output Format:** Plain Text File (`headlines.txt`)

## 📚 Interview Questions & Detailed Answers

### 1. What is a GET request?
A **GET request** is an HTTP method used to request data from a specified server resource. It asks the server to retrieve and return web pages, images, API JSON data, or documents without modifying server state. In web scraping, `requests.get(url)` sends an HTTP GET request to download the target web page's HTML code.

### 2. How do you install external packages in Python?
External third-party Python packages (hosted on the Python Package Index - PyPI) are installed using **`pip`**, Python’s package manager.
- Command: `pip install package_name`
- Example: `pip install requests beautifulsoup4`
- You can also install dependencies listed in a requirements file using `pip install -r requirements.txt`.

### 3. What is a User-Agent in HTTP?
A **User-Agent** is a request header string sent by web browsers or clients to identify the client software, operating system, vendor, and version to the web server.
- Web servers often block or restrict requests with missing, default, or automated script User-Agent headers (e.g. `python-requests/2.x.x`).
- By setting a custom browser User-Agent header (such as Chrome or Firefox headers), web scrapers mimic standard web browsers and prevent 403 Forbidden blocking.

### 4. What is `soup.find_all()` used for?
In BeautifulSoup, `soup.find_all(name, attrs, recursive, string, **kwargs)` searches through the parsed HTML DOM tree and returns a Python list containing **all** matching elements/tags that satisfy the search criteria (e.g., tag names like `'h2'`, CSS classes, or attributes).
- Example: `soup.find_all('h2')` retrieves all `<h2>` heading tags on the page.

### 5. What are the risks of web scraping?
- **IP Rate-Limiting & Blocking:** Scraping at high speed without delays can lead to IP bans or HTTP 429 (Too Many Requests) / 403 Forbidden errors.
- **Legal & Terms of Service (ToS) Violations:** Scraping copyrighted data, personal private data, or violating a website’s Terms of Service or `robots.txt` can lead to legal action.
- **Website Structure Breakdown:** Changes in website HTML structure or CSS class names break scraping scripts, requiring continuous maintenance.
- **Server Load:** Aggressive scraping can overwhelm host web servers, acting like a Denial of Service (DoS) attack.

### 6. What’s the difference between `id` and `class` in HTML?
- **`id`**: An identifier intended to be **unique** to a single HTML element on a webpage. No two elements on the same page should share the same `id`. In CSS it is selected using `#id-name`.
- **`class`**: A reusable attribute shared by **multiple** HTML elements on a page to apply common styling or groupings. In CSS it is selected using `.class-name`.

### 7. What is an HTML tag?
An **HTML tag** is a fundamental building block of HTML (HyperText Markup Language) enclosed in angle brackets (`<tagname>`). Tags inform web browsers how to format and display content on a webpage.
- Examples: `<h1>` to `<h6>` (headings), `<p>` (paragraph), `<a>` (anchor link), `<div>` (container division), and `<span>` (inline element).

### 8. What does `.text` return in BeautifulSoup?
In BeautifulSoup, accessing the `.text` (or `.get_text()`) property on a parsed Tag object extracts and returns **only the raw textual content** inside that HTML tag and its children, stripping away all surrounding HTML tags, attributes, and markup.

### 9. What is a `try-except` block?
A **`try-except` block** is Python's exception handling mechanism used to catch and manage runtime errors gracefully without crashing the program execution.
- Code that might raise an exception (such as network requests or file IO) is placed inside the `try` block.
- The `except` block catches specific errors (e.g. `requests.exceptions.HTTPError`, `IOError`, `ZeroDivisionError`) and defines fallback or recovery actions.

### 10. What are HTTP status codes?
HTTP status codes are 3-digit numerical responses returned by web servers indicating the result of an HTTP request:
- **1xx (Informational):** Request received, continuing process.
- **2xx (Success):** Request was successfully received, understood, and accepted (e.g. `200 OK`).
- **3xx (Redirection):** Further action needed to complete request (e.g. `301 Moved Permanently`).
- **4xx (Client Error):** The request contains bad syntax or cannot be fulfilled (e.g. `400 Bad Request`, `403 Forbidden`, `404 Not Found`).
- **5xx (Server Error):** The server failed to fulfill an apparently valid request (e.g. `500 Internal Server Error`, `503 Service Unavailable`).
